# sourabh-kumar2.github.io

Personal portfolio site for Sourabh Kumar — Staff Backend Engineer.

Live at: https://sourabh-kumar2.github.io/

## Stack

- React 18 + TypeScript
- Vite 5
- TailwindCSS 3
- lucide-react (icons)

## Development

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

Builds the app and publishes the `dist/` folder to the `gh-pages` branch via the `gh-pages` package.

## Content

All site content (experience, skills, projects, awards, education) is driven by [`src/data.json`](src/data.json) — edit that file to update the portfolio.
